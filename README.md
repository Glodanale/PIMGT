# PIMGT
Physics-Informed Meta Graph Transformer for Travel State Estimation via Traffic Density

## Accessible Novel Architectures:
- PartialRefinementSystem/PIMGT_Internal_Integration
- PartialRefinementSystem/PIMGT_External_Integration
- FullRefinementSystem/PIMGT_Internal_Integration
- FullRefinementSystem/PIMGT_External_Integration

#### Execution instructions included in README files in each architecture subdirectory

> PIMGT_External_Integration and PIMGT_Internal_Integration in both refinement systems are novel workflows designed by [Alex Glover](https://scholar.google.com/citations?hl=en&user=X0UDy3wAAAAJ).  Publication detailing work is in progress.

> Note: MGT_Modified is the work of http://github.com/lonicera-yx/MGT with modifications I made to make the code CUDA compatible.  I made no logical transformations from the original workflow.  This workflow is now compatible with CUDA as tested with ASUS ProArt GeForce RTX 4080 SUPER OC powered by NVIDIA DLSS3
